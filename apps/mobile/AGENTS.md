# apps/mobile — client guide

Expo SDK 51 + React Native Web + Expo Router + NativeWind v4 + TanStack Query + Zustand + React Hook Form.
Web-first; native builds are out of MVP (ADR 0011). Global rules are in the root `AGENTS.md`.

## Map

```
app/                         Expo Router file-based routes
  _layout.tsx                root layout, wraps <Providers>
  index.tsx                  redirect to /(tabs)/month
  (tabs)/                    tab navigator: month, history, analytics, envelopes
src/
  api/                       GENERATED by Orval (react-query hooks, model types) + hand-written axios-instance.ts
  components/                FormInput.tsx (RHF + NativeWind), envelopes/* (card, create/rename forms, API-error helper),
                             month/* (dashboard, period switcher, summary, envelope rows, month actions, income/first-month forms, allocation editor, quick-action operation forms)
  lib/                       pure helpers: monthVersion.ts (If-Match / ETag), useMonthMutation.ts (month-scoped mutation hook), allocation.ts (live editor totals in integer kopecks), money.ts (ru-RU display of API decimal strings), period.ts (YYYY-MM labels/navigation), apiErrors.ts (MSG-06 / 409 mapping)
  providers/                 QueryProvider (staleTime 5 min, no refetch on focus), Providers wrapper
  stores/                    Zustand: monthStore (current period), envelopeStore (selected id), uiStore (sidebar, active tab)
  types/env.d.ts             process.env typings
orval.config.js              client generation from ../api/openapi.json (committed, no server needed)
tailwind.config.js, global.css, metro.config.js, nativewind-env.d.ts   NativeWind setup
```

Screen state: the **Envelopes**, **Month**, **History** and **Analytics** screens are wired to the API (history: `src/components/history/*`, deep-link params `period`, `envelopeId`, `type`); **Analytics** (`src/components/analytics/*`: income, balances, uncovered reports; drill-down links come only from `src/lib/drillDown.ts`) is wired to `GET /analytics/yearly`.
Check `tasks/` before building a screen.

## Conventions

- Styling: `className` only; theme colors (`primary-*`, `success`, `warning`, `danger`, `info`) live in `tailwind.config.js`.
- Server state: generated React Query hooks from `src/api/**`. Local UI state only: Zustand. Do not mirror server data in stores.
- Forms: React Hook Form + `@hookform/resolvers/zod` with schemas from `@family-budget/types`; never redefine schemas locally.
- API base URL: `process.env.EXPO_PUBLIC_API_URL` = API **origin** without `/api` (default `http://localhost:3000`; `same-origin` or `/` = the page's own origin, see `src/lib/apiBaseUrl.ts`; generated paths already start with `/api/v1`); never hardcode.
- Never edit `src/api/**` (except `axios-instance.ts`) by hand — run `pnpm api:generate` from the repo root after API changes (`pnpm api:contract` fails on drift).
- Money: display API decimal strings with `formatRubles` (`src/lib/money.ts`, ru-RU) or kopecks with `formatMoneyMinor`; never show negative balances (NFR-24); send amounts as
  decimal strings. Never compute balances client-side — the server returns derived values.
- Mutations that depend on a month go through `useMonthMutation` (`src/lib/useMonthMutation.ts`): pass the displayed month's cached `version` in the variables; it is sent as `If-Match: "<version>"` (never in the body or query, API-25) and the budget data is refetched after every settled request. `ETag` of responses refreshes the cached dashboard version (`src/lib/monthVersion.ts`). On 409 `VERSION_CONFLICT` show the API message and ask the user to retry; 428 is a client bug (generic message).
- User-visible text is Russian and must match the spec `MSG-*` texts where defined. Financial date inputs are month-only (AC-21).
- Keep platform-specific code to a minimum; the app must work in a browser first.

## Tests

jest-expo + React Native Testing Library; component tests are `src/**/*.test.tsx` next to the component (example: `EnvelopeCard.test.tsx`),
helpers in `test/` (`renderWithProviders`, `ifMatchOf` for the `If-Match` of a mocked call). Mock the network at `src/api/axios-instance`. UI tasks also add Playwright specs
under `e2e/` and run `pnpm e2e:smoke`. Details: `docs/testing.md`.

## Commands

```bash
cd apps/mobile
pnpm dev                 # expo start
pnpm dev:web             # expo start --web
pnpm build:web           # expo export --platform web
pnpm typecheck
pnpm test                # jest-expo
pnpm orval               # Orval only, from apps/api/openapi.json (prefer root `pnpm api:generate`)
```

## Anti-patterns

- `StyleSheet.create`, hardcoded API URLs, duplicated Zod schemas/types, business rules in components, hand-edited generated client.
