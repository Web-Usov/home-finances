## Демо-сценарий «Критерии приёмки вехи»

Владелец проверяет через Swagger UI на стенде (http://192.168.1.114:8100/api; демо-данные стенда: месяц 2026-10, доход 150 000 ₽, распределено 96 000 ₽). Запросы только на чтение, стенд не ломают.

1. **Дашборд (`AC-02`).** `GET /api/v1/dashboard/monthly?period=2026-10`. Ожидается: `summary.income = "150000.00"`, `summary.allocated = "96000.00"`, `summary.free = "54000.00"` (доход минус распределение). Проверено на стенде 2026-11-01: ответ 200 с этими значениями. Пример из эпика (100 000 ₽ и 75 000 ₽ → свободно 25 000 ₽) проверяет тест `AC-02` в `reporting.monthly-dashboard.int-spec.ts`.
2. **Перевод не меняет «Пополнено» и «Списано» (`AC-19`).** Выполните `POST /operations` с типом `transfer` между двумя конвертами (в заголовке `If-Match` версия месяца из `ETag` дашборда), затем повторите дашборд. Ожидается: у обоих конвертов изменился `closing`, `replenished` и `spent` у них и в `summary` те же, что до перевода; `transfersIn`/`transfersOut` выросли. На стенде у «Отпуска» уже есть `transfersIn: 5000.00`, `transfersOut: 1.00`.
3. **Годовая аналитика (`AC-20`).** `GET /api/v1/analytics/yearly?year=2026`. Ожидается: три блока `incomeReport`, `envelopeBalances`, `uncoveredOperations`, в каждом по 12 месяцев (`periods[12]` / `months[12]`); месяцы без данных дают `null` (или `exists: false`); архивный конверт сохраняется в `envelopeBalances.envelopes[]` со `status: "archived"`. `GET …?year=abc` → 422.
4. **Детализация.** `GET /api/v1/operations?period=2026-10&uncoveredOnly=true&role=source` возвращает только операции, в которых есть непокрытая часть, по конверту-источнику; их сумма равна числу из `uncoveredOperations`.
5. **Интеграционные тесты.** `pnpm --filter @family-budget/api test:int` зелёный и ссылается на `AC-02`, `AC-19`, `AC-20` (подтверждено `pnpm spec:check --verbose`: AC 22/22).

## Известные ограничения и риски

- Значения читаются из снимков `EnvelopeMonthSnapshot` и **не пересчитываются** при чтении. Если снимки не обновлены (не должно быть после T-032), дашборд покажет нули. Страховка: тесты каскада в E-01.
- Свободные средства (`free`) могут быть отрицательными (черновик с нулевым доходом и скопированным распределением до ввода дохода, FIN-11). На стенде черновик 2026-11 создан до T-041 и поэтому имеет доход 0 и свободно −96 000 ₽; новые месяцы копируют доход.
- Предупреждение `ARCHIVED_ENVELOPE_WITH_BALANCE` вычисляется заново при чтении (движок не сохраняет предупреждения).
- Ключи `drillDown` в годовом отчёте не расширены (T-045): фильтры `uncoveredOnly`/`role=source` добавляет клиент при переходе в историю, контракт ответа не менялся.
- Стенд собран из коммита `5a960a6` (T-045), `master` на момент отчёта впереди на T-044 (рефакторинг без изменения поведения).
