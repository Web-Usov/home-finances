# 60. Интерфейс и экраны

> **Назначение файла:** навигация, разделы приложения, месячный дашборд, редактор распределения и тексты предупреждений и ошибок.
> **Префиксы ID:** `UI` (экраны и поведение), `MSG` (тексты сообщений — приводятся дословно).

**[UI-01]** Стартовый экран после запуска — месячный дашборд. На телефоне используется нижняя навигация, на широком экране — боковая. Основные разделы: «Месяц», «История», «Аналитика», «Конверты».

| ID | **Раздел** | **Назначение** | **Основное содержимое** | **Действия** |
|----|------------|----------------|-------------------------|--------------|
| **[UI-02]** | Месяц | Дашборд, переключатель периода, статус | Доход, распределение, свободные средства, корректировки, непокрытые суммы, конверты | Добавить операцию; изменить доход/распределение; закрыть или открыть месяц |
| **[UI-03]** | История | Последовательность операций | Тип, конверт(ы), сумма, покрыто, не покрыто, комментарий | Фильтровать; редактировать; удалить |
| **[UI-04]** | Аналитика | Годовые показатели | Три группы отчётов, выбранные для MVP | Сменить год; выбрать конверты; открыть детализацию месяца |
| **[UI-05]** | Конверты | Единый список активных и архивных | Название, статус, текущий остаток, месяц создания/архива | Создать; переименовать; изменить порядок; архивировать |

## Месячный дашборд

- **[UI-06]** **Шапка периода.** Переключатели месяца и года, статус, действия «Создать следующий», «Закрыть», «Открыть повторно».

- **[UI-07]** **Сводные показатели.** Доход, распределено, свободно, чистая применённая корректировка, общая непокрытая сумма с разбивкой по типам.

- **[UI-08]** **Конверты.** Для каждого конверта: остаток на конец/текущий момент, пополнение распределением за месяц и полная сумма списаний за месяц.

- **[UI-09]** **Корректировки.** Показываются отдельным индикатором и не смешиваются с доходом, распределением, пополнениями и списаниями.

- **[UI-10]** **Быстрые действия.** «Списать», «Перевести», «Скорректировать»; в закрытом месяце они отключены.

## Редактор распределения

- **[UI-11]** одно поле общего дохода и одна строка на каждый активный конверт;

- **[UI-12]** в новом месяце суммы копируются из предыдущего как редактируемые значения;

- **[UI-13]** внизу постоянно видны итог распределения и свободные средства;

- **[UI-14]** при превышении дохода сохранение блокируется и показывается точная сумма превышения;

- **[UI-15]** изменение распределения пересчитывает уже добавленные операции этого и последующих месяцев.

## Предупреждения и тексты ошибок

| ID | **Ситуация** | **Сообщение** | **Поведение** |
|----|--------------|---------------|---------------|
| **[MSG-01]** | Распределение выше дохода | «Распределено на X ₽ больше дохода. Уменьшите суммы по конвертам.» | Сохранение заблокировано |
| **[MSG-02]** | Списание выше остатка | «В конверте доступно X ₽. Y ₽ будут отмечены как непокрытые.» | Разрешить после подтверждения |
| **[MSG-03]** | Перевод выше остатка | «Доступно X ₽. Перевести только X ₽?» | Исходная сумма не сохраняется; доступна замена |
| **[MSG-04]** | Отрицательная корректировка выше остатка | «Баланс станет 0 ₽, Y ₽ будут отмечены как непокрытые.» | Разрешить после подтверждения |
| **[MSG-05]** | Архивирование ненулевого конверта | «Сначала обнулите конверт. Текущий остаток: X ₽.» | Архивирование заблокировано |
| **[MSG-06]** | Действие в закрытом месяце | «Месяц закрыт. Откройте его повторно, чтобы внести изменения.» | Изменение заблокировано |
