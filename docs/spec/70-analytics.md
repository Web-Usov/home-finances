# 70. Годовая аналитика

> **Назначение файла:** обязательные годовые отчёты MVP.
> **Префикс ID:** `REP`.

**[REP-01]** В первой версии обязательны три отчёта. Все они работают для выбранного календарного года и допускают переход в детализацию месяца.

## Доход, распределение и свободные средства

- **[REP-02]** группированная диаграмма по 12 месяцам;

- **[REP-03]** таблица с точными значениями и годовыми итогами;

- **[REP-04]** свободные средства показываются исторически и не суммируются с балансами конвертов.

## Баланс каждого конверта по месяцам

- **[REP-05]** таблица «конверт × месяц» с закрывающими балансами;

- **[REP-06]** фильтр активных и архивных конвертов;

- **[REP-07]** на графике пользователь выбирает один или несколько конвертов, чтобы избежать нечитаемого набора линий.

## Непокрытые операции

- **[REP-08]** сумма непокрытых списаний по месяцам — обязательный основной показатель;

- **[REP-09]** дополнительные разрезы: непокрытые переводы и отрицательные корректировки;

- **[REP-10]** для каждого значения доступен переход к строкам истории;

- **[REP-11]** непокрытые суммы не включаются в долг и не уменьшают будущие пополнения.
