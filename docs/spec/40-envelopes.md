# 40. Управление конвертами

> **Назначение файла:** свойства конверта, создание, изменение, удаление и архивирование.
> **Префикс ID:** `ENV`.

## Свойства конверта

- **[ENV-01]** идентификатор, уникальное название, порядок отображения и статус «Активен/Архивный»;

- **[ENV-02]** месяц создания и, при наличии, месяц архивирования;

- **[ENV-03]** необязательный стартовый остаток, оформленный отдельной стартовой корректировкой;

- **[ENV-04]** цель, плановая сумма и дедлайн отсутствуют в MVP.

## Создание, изменение и удаление

- **[ENV-05]** создание разрешено в открытом, повторно открытом месяце и черновике;

- **[ENV-06]** название обязательно, сравнивается без учёта регистра и должно быть уникальным среди всех сохранённых конвертов, включая архивные;

- **[ENV-07]** название и порядок можно менять без пересчёта финансовых данных;

- **[ENV-08]** полное удаление разрешено только для ошибочно созданного конверта без стартового остатка, распределений и операций;

- **[ENV-09]** во всех остальных случаях используется архивирование.

## Архивирование

- **[ENV-10]** архивировать можно только конверт с балансом 0 ₽ на момент операции;

- **[ENV-11]** при ненулевом балансе сохранение блокируется, а интерфейс предлагает перевод, отрицательную корректировку либо отмену;

- **[ENV-12]** архивный конверт исключается из новых распределений и операций, но остаётся в истории и аналитике;

- **[ENV-13]** остатки и операции до месяца архивирования отображаются без изменений.
