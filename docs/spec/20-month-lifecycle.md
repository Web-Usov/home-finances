# 20. Жизненный цикл месяца

> **Назначение файла:** статусы месяца, правила переходов, закрытие и повторное открытие.
> **Префикс ID:** `MON`.

| ID | **Статус** | **Назначение** | **Доступные действия** |
|----|------------|----------------|------------------------|
| **[MON-01]** | Черновик | Следующий календарный месяц | Разрешены доход, распределение, конверты и любые операции; закрытие запрещено |
| **[MON-02]** | Открыт | Текущий рабочий месяц | Все действия разрешены; месяц можно закрыть |
| **[MON-03]** | Закрыт | Зафиксированный месяц | Доход, распределение, списания, переводы, корректировки и управление конвертами заблокированы |
| **[MON-04]** | Открыт повторно | Исторический месяц на исправлении | Редактирование разрешено; каждый шаг пересчитывает все последующие месяцы |

## Правила переходов

- **[MON-05]** первый созданный месяц получает статус «Открыт»;

- **[MON-06]** можно создать только непосредственно следующий месяц без календарных пропусков;

- **[MON-07]** если текущий месяц открыт, следующий создаётся только как черновик; одновременно допускается не более одного будущего черновика;

- **[MON-08]** после закрытия текущего месяца черновик автоматически становится открытым;

- **[MON-09]** при отсутствии черновика следующий месяц после закрытого создаётся сразу открытым;

- **[MON-10]** закрытие разрешено при любом размере свободных средств и не сопровождается специальным предупреждением о нераспределённой сумме;

- **[MON-11]** закрытие блокируется только при нарушении жёстких инвариантов, например распределении выше дохода; непокрытые операции закрытию не мешают.

## Повторное открытие

- **[MON-12]** перед открытием показывается предупреждение с диапазоном месяцев, которые будут пересчитаны;

- **[MON-13]** в MVP одновременно может быть только один исторический месяц со статусом «Открыт повторно»;

- **[MON-14]** текущий открытый месяц и будущий черновик сохраняют свои статусы; закрытые последующие месяцы остаются заблокированными, но их производные показатели обновляются;

- **[MON-15]** повторное закрытие исторического месяца возвращает ему статус «Закрыт» и не переводит черновик в открытый.
