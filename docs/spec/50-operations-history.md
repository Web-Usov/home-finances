# 50. Операции и история

> **Назначение файла:** общие поля операций, правила редактирования и удаления, представление истории.
> **Префикс ID:** `HIST`.

## Общие поля

- **[HIST-01]** месяц операции; точная дата отсутствует;

- **[HIST-02]** тип: списание, перевод, корректировка или стартовый остаток;

- **[HIST-03]** конверт-источник; для перевода также конверт-получатель;

- **[HIST-04]** полная запрошенная сумма, применённая/покрытая сумма и непокрытая часть;

- **[HIST-05]** необязательный комментарий длиной до 500 символов;

- **[HIST-06]** внутренний sequence_no и технические created_at/updated_at.

## Редактирование

- **[HIST-07]** в черновике, открытом и повторно открытом месяце операцию можно изменить или удалить;

- **[HIST-08]** редактирование не меняет последовательность, удаление запускает пересчёт;

- **[HIST-09]** ручное изменение перевода снова проходит проверку доступного остатка; непокрытый перевод нельзя создать намеренно;

- **[HIST-10]** финансовые записи закрытого месяца доступны только для чтения;

- **[HIST-13]** «доступный остаток» из HIST-09 при изменении перевода — остаток конверта-источника в позиции этого перевода по `sequence_no` (OP-16) после пересчёта без прежнего эффекта изменяемого перевода: учитываются начальный остаток, распределение и операции, стоящие в последовательности раньше. Операции, стоящие позже, на проверку не влияют; если после изменения они становятся непокрытыми, это обычный результат каскада (OP-05, OP-09);

- **[HIST-14]** операция типа «стартовый остаток» (OP-10) создаётся только вместе с конвертом: её нельзя изменить или удалить через `PATCH`/`DELETE /api/v1/operations/{id}` (API-11). Такой запрос отклоняется как 422 `VALIDATION_ERROR` (API-17).

## Представление истории

**[HIST-11]** История по умолчанию показывает операции выбранного месяца в порядке добавления. Доступны фильтры по году, месяцу, конверту и типу. Для каждой строки отображаются полная сумма, применённая сумма, непокрытая часть, комментарий и предупреждающий статус.

**[HIST-15]** Для переходов из аналитики (REP-10) `GET /api/v1/operations` принимает дополнительные необязательные фильтры: `role=source` — только операции, где конверт из фильтра `envelopeId` является источником (получатель перевода не учитывается; `role=source` без `envelopeId` — 422 `VALIDATION_ERROR`, а не молча игнорируется), и `uncoveredOnly=true` — только операции с непокрытой частью больше нуля. Так по ссылке REP-10 открываются ровно те строки, из которых сложено число отчёта, без лишних (например, положительных корректировок при типе «корректировка»).

> **[HIST-12]** **Переводы.** Обычные переводы отображаются только в истории. На месячном дашборде они не увеличивают «Пополнено» и не увеличивают «Списано». В аналитике исключение составляют только непокрытые переводы.
