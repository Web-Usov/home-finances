# 01. Глоссарий

> **Назначение файла:** определения терминов, используемых во всей спецификации.
> **Префикс ID:** `TERM`.

| ID | **Термин** | **Определение** |
|----|------------|-----------------|
| **[TERM-01]** | Месяц | Период формата YYYY-MM. Точная дата операции не используется. |
| **[TERM-02]** | Доход | Одна общая неотрицательная сумма, доступная для распределения в выбранном месяце. |
| **[TERM-03]** | Распределение | Суммы, зачисляемые в конверты в начале месяца до любых операций. |
| **[TERM-04]** | Свободные средства | Доход минус распределение. Показатель хранится в истории месяца, но не переносится дальше. |
| **[TERM-05]** | Конверт | Накопительный баланс без обязательной цели и срока. Остаток переносится между месяцами и годами. |
| **[TERM-06]** | Списание | Расход из одного конверта. Полная сумма сохраняется даже при недостатке денег. |
| **[TERM-07]** | Перевод | Перемещение суммы из одного конверта в другой; не считается пополнением или списанием на дашборде. |
| **[TERM-08]** | Корректировка | Ручное изменение баланса конверта, показываемое отдельным показателем. |
| **[TERM-09]** | Непокрытая часть | Часть операции, для которой не хватило остатка. Это аналитический показатель, а не долг. |
