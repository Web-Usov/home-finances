# 99. Открытые решения

> **Назначение файла:** решения, которые нужно принять до публикации. Отложенные функции («Вне MVP») перечислены в [00-scope.md](00-scope.md) (SCOPE-16…SCOPE-22).
> **Префикс ID:** `Q`.

## Решения до публикации

- **[Q-01]** выбрать место размещения: домашний сервер либо облако;

- **[Q-02]** если доступ будет не только из приватной сети — добавить встроенную авторизацию или обязательную внешнюю защиту;

- **[Q-03]** утвердить название продукта, визуальную тему и домен; эти решения не меняют финансовую модель и API-контракт.

> **Итог версии 1.0.** Требования финансовой логики, операций, закрытия месяцев, интерфейса и приёмки зафиксированы. Неопределённым остаётся только способ размещения и связанная с ним защита доступа.
