# 99. Открытые решения

> **Назначение файла:** решения, которые нужно принять до публикации. Отложенные функции («Вне MVP») перечислены в [00-scope.md](00-scope.md) (SCOPE-16…SCOPE-22).
> **Префикс ID:** `Q`.

## Решения до публикации

- **[Q-01]** выбрать место размещения: домашний сервер либо облако;

- **[Q-02]** если доступ будет не только из приватной сети — добавить встроенную авторизацию или обязательную внешнюю защиту;

- **[Q-03]** утвердить название продукта, визуальную тему и домен; эти решения не меняют финансовую модель и API-контракт.

- ~~**[Q-04]** единая форма ответа мутаций месяца~~ (решено 2026-10-31 человеком: вариант B — все мутации месяца возвращают `data.summary` с краткой сводкой `MonthSummary`, остатки конвертов берутся из `GET /api/dashboard/monthly`; нормативное правило — API-22). Рассматривались: (A) оставить как есть; (B) выбранный вариант; (C) полная сводка с остатками конвертов во всех мутациях.

- **[Q-05]** начальные значения нового месяца (черновика): сейчас распределение копируется из прошлого месяца (SCOPE-29), а доход равен 0 — до ввода дохода распределение превышает доход, что противоречит FIN-02. Варианты: (A) копировать и доход прошлого месяца (если доход не передан в запросе) — **рекомендуется**: FIN-02 выполняется с первой секунды, свободные средства совпадают с прошлым месяцем, пользователю остаётся поправить цифры; (B) доход 0 и распределение не копируется, а предлагается в редакторе кнопкой «Скопировать из прошлого месяца» — строже по FIN-02, но больше действий; (C) оставить как есть и разрешить для черновика временное нарушение FIN-02 (отрицательные свободные средства, NFR-30) — требует исключения из FIN-02 и запрета закрытия до исправления. Реализацию блокирует задача T-041.
