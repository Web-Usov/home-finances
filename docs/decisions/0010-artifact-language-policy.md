# 0010. Язык артефактов

## Статус

Принято (2026-10-28). Действует.

## Контекст

Владелец читает требования и решения по-русски; агенты и код работают стабильнее на английском. Раньше язык смешивался: русские AGENTS.md и ТЗ рядом с английскими комментариями.

## Решение

- **Русский** (для человека): эпики, ключевые фичи, правила спецификации (`docs/spec/**`), ADR (`docs/decisions/**`).
- **Английский** (для агентов и разработки): детальные задачи (`tasks/**`), все AGENTS.md, workflow/testing/architecture-документы, конфиги агентов, код, комментарии, тесты, сообщения коммитов и PR (исключения для PR и сообщений человеку — в дополнении ниже).
- **Строки интерфейса остаются русскими** (приложение для ru-RU; тексты сообщений — MSG-*).
- На правила спецификации ссылаются по ID (`OP-04`), а не по номерам строк.

## Дополнение (2026-11-01)

Решение владельца: документы для разработки, которые читают агенты, остаются английскими, но **всё, что предназначено для ревью или решения человека, пишется по-русски**, чтобы владельцу было удобно читать и отвечать. Если ревью человека не требуется, допустим английский.

Конкретно:

- **Русский:** тело PR, которому нужен ревью/мерж человека (затронуты `docs/spec/**`, `docs/decisions/**`, `epics/**` или это отчёт о вехе) — начинается с «⚠️ Требуется ревью человека», шаблон `.github/PULL_REQUEST_TEMPLATE/human-review.md`; вопросы, варианты и рекомендации человеку (записи `Q-NN`, вопросы в PR, эскалации `blocked` / `Q-proposal`) в формате «Вопрос / Варианты / Рекомендация / Затронутые правила / Задачи»; отчёты о вехах; вердикты ревьюера на PR, ждущих мержа человека (ключевые слова `VERDICT: LGTM | CHANGES REQUESTED` сохраняются); уведомления и итоговые сообщения человеку.
- **Английский:** заголовки PR (conventional commit, из них получаются squash-коммиты), коммиты, код, тесты, детальные задачи, а также тела и вердикты PR только для агентов (мержатся автоматически после ревью).
- Соблюдение проверяет ревьюер: русское тело PR для ревью человека обязательно, иначе замечание уровня blocker.

Правило закреплено в `AGENTS.md` («Language rule»), `docs/workflow.md` (разделы 5–8) и промптах агентов/команд.

## Последствия

- Нарушение языка — повод для замечания ревьюера.
- Язык новой категории артефактов определяется по назначению: «читает человек» — русский, «читает/пишет агент» — английский.
