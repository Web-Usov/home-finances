# 0010. Язык артефактов

## Статус

Принято (2026-10-28). Действует.

## Контекст

Владелец читает требования и решения по-русски; агенты и код работают стабильнее на английском. Раньше язык смешивался: русские AGENTS.md и ТЗ рядом с английскими комментариями.

## Решение

- **Русский** (для человека): эпики, ключевые фичи, правила спецификации (`docs/spec/**`), ADR (`docs/decisions/**`).
- **Английский** (для агентов и разработки): детальные задачи (`tasks/**`), все AGENTS.md, workflow/testing/architecture-документы, конфиги агентов, код, комментарии, тесты, сообщения коммитов и PR.
- **Строки интерфейса остаются русскими** (приложение для ru-RU; тексты сообщений — MSG-*).
- На правила спецификации ссылаются по ID (`OP-04`), а не по номерам строк.

## Последствия

- Нарушение языка — повод для замечания ревьюера.
- Язык новой категории артефактов определяется по назначению: «читает человек» — русский, «читает/пишет агент» — английский.
