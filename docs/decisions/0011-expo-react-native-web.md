# 0011. Клиент: Expo + React Native Web + Expo Router

## Статус

Принято (2026-08-03). Действует.

## Контекст

Спецификация требует адаптивное веб-приложение (NFR-01, NFR-20); нативные приложения iOS/Android вне MVP (SCOPE-22). Владелец явно указал стек Expo + React Native Web вместо более простого Next.js, чтобы оставить путь к мобильным сборкам (`docs/archive/omo/drafts/repo-init.md`).

## Решение

- Клиент — `apps/mobile`: Expo SDK 51, React Native Web, файловая маршрутизация Expo Router; вкладки «Месяц», «История», «Аналитика», «Конверты».
- Стили — только NativeWind v4 (проп `className`); `StyleSheet.create` не используется.
- Серверное состояние — TanStack Query, локальное UI-состояние — Zustand, формы — React Hook Form + Zod.
- EAS Build настроен как заглушка; нативные сборки не входят в MVP.

## Последствия

- Код пишется web-first; платформенно-специфичные ветки добавляются только при необходимости.
- Решение обратимо: миграция на чистый web-фреймворк возможна позже.
