# 0002. Без авторизации в MVP

## Статус

Принято (2026-08-03). Действует до решения Q-02.

## Контекст

Продукт рассчитан на одного пользователя в частной сети (SCOPE-11, SCOPE-15, NFR-05). Встроенная авторизация (Clerk, JWT) добавила бы сложность, не нужную в сценарии «домашний сервер»; в начальном плане её сознательно пропустили (`docs/archive/omo/drafts/repo-init.md`).

## Решение

- В приложении нет аутентификации, авторизации, пользователей и ролей; auth middleware и guard'ы не добавляются.
- Безопасность обеспечивается снаружи: приватная сеть, VPN или защита на reverse proxy (SCOPE-15).
- CORS в API открыт (`origin: '*'`, без credentials), так как cookie и сессий нет.

## Последствия

- Приложение нельзя публиковать в открытый интернет без внешней защиты.
- Добавление авторизации — отдельная фича вне MVP (SCOPE-16) и новое ADR; агентам запрещено добавлять её «по пути».
- Открытое решение: Q-02.
