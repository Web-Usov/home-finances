# 0012. API-клиент генерируется из OpenAPI (Orval)

## Статус

Принято (2026-08-03). Действует.

## Контекст

Ручные клиенты и типы запросов расходятся с бэкендом. Бэкенд публикует OpenAPI (Swagger) со схемами запросов, выведенными из Zod (см. 0003).

## Решение

- Клиент мобильного приложения (React Query хуки) генерируется Orval из `/api/swagger.json` в `apps/mobile/src/api` (режим `tags-split`, мутатор `customAxiosInstance`).
- Сгенерированный код руками не правится.
- Базовый URL берётся из `EXPO_PUBLIC_API_URL`, не хардкодится.
- Расхождение контракта и сгенерированного клиента ловится проверкой `api:contract` (регенерация и сравнение с git; вводится в рамках quality gate).

## Последствия

- Любое изменение контроллеров и схем требует регенерации клиента в том же PR.
- Маршруты версионируются через URI (`/api/v1/...`), что отражается в именах хуков (`...V1`).
