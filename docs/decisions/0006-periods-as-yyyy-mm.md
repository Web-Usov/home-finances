# 0006. Периоды YYYY-MM без дней

## Статус

Принято (2026-08-03). Действует.

## Контекст

Финансовой датой в продукте является только месяц (TERM-01, SCOPE-14, AC-21). Точные даты усложняют порядок операций и пересчёт без пользы для сценария «конвертов».

## Решение

- Период — строка `YYYY-MM` (`PeriodSchema`, regex `/^\d{4}-\d{2}$/`; в БД `VarChar(7)`, уникальный).
- Поля дня в формах и API отсутствуют. Порядок операций внутри месяца задаётся стабильным `sequence_no` (OP-16, OP-17), а не датой.
- `created_at`/`updated_at` — технические метки в UTC, не финансовая дата (FIN-10).
- Строки `YYYY-MM` сравниваются лексикографически — это совпадает с хронологическим порядком.

## Последствия

- Нельзя добавить «дату операции» без пересмотра спецификации и этого ADR.
- Следующий месяц вычисляется арифметикой над строкой периода; пропуски месяцев запрещены (MON-06).
