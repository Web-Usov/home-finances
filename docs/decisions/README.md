# Архитектурные решения (ADR)

Каждое значимое решение фиксируется отдельным файлом `NNNN-kebab-title.md` с разделами **Статус / Контекст / Решение / Последствия**. Язык — русский (см. 0010).

## Правила

- Номера сквозные и не переиспользуются.
- Принятое ADR не переписывается задним числом: при смене решения создаётся новое ADR, в старом меняется статус на «Заменено ADR NNNN».
- На правила спецификации ссылаться по ID (`OP-04`), на другие ADR — по номеру.
- Изменения в `docs/decisions/**` требуют ревью человека (CODEOWNERS).
