# Дизайн-бриф

> **Назначение:** задание на визуальный дизайн приложения (эпик [E-07](../../epics/E-07-design.md)). Дизайн создаётся владельцем в **отдельной сессии агента с MCP Doop** (общий холст). В репозитории хранятся только бриф, ссылка на холст и документ передачи в разработку. Вёрстки и кода в этом эпике нет.
> **Язык:** русский (документ читает владелец). Правила спецификации указываются по ID.

**Канвас:** _(пока пусто; ссылку на холст «Family Budget — Design» вписывает владелец после создания)_

## 1. Цели и принципы

Нужен качественный, современный, свежий, минималистичный и понятный дизайн для личного финансового инструмента. Не «ещё один шаблон из генератора интерфейсов».

Принципы:

1. **Цифры — главный герой.** Сумма — самый заметный элемент строки. Табличные (моноширинные) цифры, выравнивание сумм по десятичной запятой/правому краю, единый формат ru-RU: «1 234,50 ₽» (неразрывный пробел между разрядами и перед «₽», всегда две цифры копеек, `MSG-07`).
2. **Ясность важнее украшений.** Один главный вопрос на экран; второстепенное — тоном и размером, а не рамками.
3. **Спокойная «финансовая» эстетика.** Сдержанная палитра, много воздуха, один акцентный цвет. Тревожные цвета (warning/danger) зарезервированы за реальными проблемами: превышение распределения, непокрытые суммы, закрытый месяц.
4. **Высокая плотность без перегруза.** Много данных на экране (таблицы, ряды конвертов), но с жёсткой типографической иерархией и сеткой, а не за счёт мелкого шрифта и линий-разделителей везде.
5. **Не только цвет.** Статус и знак всегда дублируются текстом/иконкой/формой (`NFR-22`). Отрицательная сумма — со знаком «−» (типографским минусом U+2212) и, при необходимости, цветом.
6. **Один язык: русский.** Тексты `MSG-01`…`MSG-06` в макетах дословно; остальные подписи не нормативны (`UI-17`), но грамматически корректны (падежи месяцев).
7. **Только месяц.** Нигде нет выбора дня или точной даты; финансовая дата — «ноябрь 2026» (`AC-21`).
8. **Mobile-first, затем десктоп.** Базовая раскладка 360/390 px; на широком экране — боковая навигация и использование ширины под таблицы (`UI-01`, `NFR-20`).

## 2. Анти-паттерны «нейрослопа» и проверка

### Чего не делать

- Фоновые градиентные «пятна» (blobs), случайные фиолетово-синие градиенты, градиентный текст, неоновые свечения.
- «Стеклянная» эстетика (glassmorphism) и размытие фона ради эффекта.
- Эмодзи вместо иконок; смешение наборов иконок разной толщины и стиля.
- Раскладка «карточка на карточке»: каждый блок в рамке с тенью и скруглением. Группировать отступами, типографикой и тонкими разделителями; карточки — только там, где объект самостоятельный.
- Универсальные стоковые иллюстрации («люди с графиками», 3D-монетки), декоративные картинки без смысла. Пустые состояния — короткий текст и действие, при необходимости простая иконка из набора.
- Несогласованные отступы и радиусы; значения вне сетки 4/8 и вне шкалы токенов.
- Больше одного акцентного цвета «для красоты»; цвет без смысла; тени разной «высоты» на одном уровне.
- Крупные скругления и пухлые кнопки везде одинаково; чрезмерно жирные заголовки; текст капсом для всего.
- Декоративные тексты-заглушки (lorem ipsum, «Ваши финансы под контролем»): только реалистичные демо-данные (раздел 8).
- Шрифтовые смеси: больше двух семейств; шрифт без кириллицы или без табличных цифр.
- Мелкий серый текст на сером фоне (контраст ниже WCAG AA).

### Чек-лист ревью дизайна

Каждый кадр перед статусом `ready_for_dev` проходит список (владелец отмечает в комментарии кадра):

- [ ] Все цвета, размеры шрифта, отступы, радиусы и тени взяты из токенов; нет «магических» значений.
- [ ] Сетка 4/8 соблюдена; выравнивание по левому краю, суммы выровнены по правому/десятичной запятой.
- [ ] Суммы: табличные цифры, формат «1 234,50 ₽», минус «−», две цифры копеек, неразрывные пробелы.
- [ ] Статус и ошибки понятны без цвета (иконка/текст/форма); контраст текста ≥ 4,5:1, крупного ≥ 3:1, элементов управления ≥ 3:1.
- [ ] Цели касания ≥ 44 × 44 px; видимое состояние фокуса; заметные состояния pressed/disabled/error.
- [ ] На 360 px нет горизонтальной прокрутки (`NFR-20`); таблицы либо перестраиваются, либо имеют осмысленную прокрутку внутри блока.
- [ ] Иконки из одного набора, один размер/толщина линии на уровень.
- [ ] Нет пунктов списка «чего не делать»; ни одного блока, который можно убрать без потери смысла.
- [ ] Тексты MSG-01…MSG-06 дословно; в формах нет выбора дня (`AC-21`).
- [ ] Показаны все состояния экрана: норма, пусто, загрузка, ошибка, только чтение (закрытый месяц).

## 3. Ограничения платформы

Дизайн должен быть реализуем без нестандартных усилий на стеке проекта (ADR 0011):

- **Expo / React Native Web + NativeWind v4.** Стили — классы в стиле Tailwind. Поэтому токены дизайна обязаны ложиться на `theme` Tailwind: цвета (`primary-*`, `success`, `warning`, `danger`, `info`, нейтральная шкала), шрифты (`fontFamily`, `fontSize` с `lineHeight`), отступы (шаг 4 px), радиусы (`borderRadius`), тени (`boxShadow`/elevation) и обводки. Каждый токен — имя + значение; без градиентов и эффектов, которых нет в Tailwind/React Native Web (или явно помеченных как «только веб»).
- **Размеры:** mobile-first 360 и 390 px; адаптация для десктопа (веб): боковая навигация (`UI-01`), ширина контента ограничена, таблицы используют ширину. Промежуточный планшетный вид — по необходимости.
- **Доступность:** контраст WCAG 2.1 AA (`NFR-23`); цели касания ≥ 44 px; управление с клавиатуры и видимый фокус; подписи у полей; статус не только цветом (`NFR-22`).
- **Язык и формат:** интерфейс на русском; суммы ru-RU; даты — только месяц (`AC-21`); отрицательные балансы конвертов не показываются (`NFR-24`), а «свободные средства» при превышении распределения показываются со знаком «−» и выделением (`NFR-30`).
- **Шрифт:** хорошая кириллица, табличные цифры (`font-variant-numeric: tabular-nums`), доступность в Google Fonts/самохостинге (лицензия OFL). Не более двух семейств (одно допустимо). Варианты для выбора владельцем:
  1. **Inter** — нейтральный, отличные табличные цифры и широкий набор начертаний; самый «безопасный» выбор, но самый распространённый.
  2. **IBM Plex Sans** — выразительнее, с характером; хорошая кириллица, табличные цифры; сочетается с Plex Mono для крупных сумм.
  3. **Golos Text** (ParaType) — разработан с учётом кириллицы, тёплый и читаемый; табличные цифры нужно проверить на холсте.
  Выбор фиксируется первой задачей эпика (с образцами сумм «1 234,50 ₽», «−3 500,00 ₽» на холсте).
- **Иконки:** один набор линейных (или залитых) иконок с единой толщиной; в Doop подбираются через `search_icons`. Кандидаты: Lucide, Phosphor, Tabler (проверить, что они реализуемы в Expo, например через SVG-компоненты).

## 4. Инвентарь экранов и состояний

Каждый пункт — кадр (или группа кадров) в Doop; мобильный вариант обязателен, широкий — для ключевых экранов с пометкой «+ десктоп».

### Общие

- Навигация: нижний таб-бар (телефон) и боковая панель (десктоп) с разделами «Месяц», «История», «Аналитика», «Конверты» (`UI-01`); активный/неактивный/фокус.
- Переключатель месяца и года, статус месяца (бейдж), главные действия шапки (`UI-06`).
- Уведомления (успех, информация), ошибки сети/API, версия устарела (409), загрузка (скелетоны), пустые состояния.

### Месяц (+ десктоп) (`UI-02`, `UI-06`…`UI-10`, `UI-16`)

- Месяц **открыт** (норма; есть непокрытые суммы; есть корректировки).
- Месяц **черновик** (доход и распределение редактируются, операции можно добавлять по `UI-16`).
- Месяц **закрыт** (только чтение, быстрые действия отключены, `MSG-06`).
- Месяц **открыт повторно** (заметный статус, подсказка о пересчёте).
- **Пустое состояние первого месяца** (первоначальная настройка: выбор месяца, доход, конверты со стартовыми остатками, `SCOPE-23`…`SCOPE-26`).
- Сводка: доход, распределено, свободно (в том числе отрицательное, `NFR-30`), чистая корректировка, непокрытые суммы по типам; строки конвертов (остаток, пополнение, списания).
- Редактор распределения (+ десктоп): норма; превышение дохода с точной суммой (`UI-14`, `MSG-01`, сохранение заблокировано); только чтение; постоянно видимый итог и свободные средства (`UI-13`).

### Операции (`UI-10`, `MSG-02`…`MSG-04`)

- Форма **списания**: норма; предупреждение о непокрытой части (`MSG-02`) с подтверждением.
- Форма **перевода**: норма; отказ при превышении остатка с предложением «Перевести только X ₽» (`MSG-03`).
- Форма **корректировки ±**: положительная; отрицательная с предупреждением (`MSG-04`).
- Поле суммы (деньги), выбор конверта (в том числе архивного источника при правке), комментарий, выбор месяца (только месяц, `AC-21`), ошибки валидации.
- **Окно повторного открытия** с диапазоном пересчёта («с … по …»), подтверждение и отмена.

### История (+ десктоп) (`UI-03`)

- Список операций (тип, конверты, сумма, покрыто / не покрыто, комментарий); пустой список.
- Фильтры (месяц, конверт, тип), чип «Только непокрытые» (`HIST-15`), сброс.
- Правка и удаление операции (подтверждение); закрытый месяц (только чтение).

### Аналитика (+ десктоп) (`UI-04`, `REP-01`…`REP-11`)

- Выбор года; три отчёта: доход/распределение/свободные средства (график + таблица с итогами), баланс конвертов по месяцам (таблица «конверт × месяц», фильтр активных/архивных, график с выбором конвертов), непокрытые операции (по типам, переход в историю).
- Вариант на 360 px (таблицы без горизонтальной прокрутки всей страницы), пустой год, загрузка.

### Конверты (`UI-05`)

- Список активных и архивных (название, статус, остаток, месяц создания/архива).
- Создание, переименование, изменение порядка, архивирование.
- Ошибка архивирования ненулевого конверта (`MSG-05`); пустой список.

## 5. Дизайн-кит

### Токены

| Группа | Что определить |
| --- | --- |
| Цвет | нейтральная шкала (50…900) для текста, фона, границ; один акцентный цвет (шкала); семантика: success, warning, danger, info (каждый: фон, обводка, текст, иконка); поверхности (фон страницы, поверхность, приподнятая, оверлей) |
| Типографика | семейство, размеры + межстрочные (заголовки, текст, подписи, крупные суммы, суммы в таблицах), насыщенность, табличные цифры, правила переноса |
| Отступы | шкала 4/8 px (4, 8, 12, 16, 24, 32, 48…) и правила: внутренние отступы, расстояния между группами, поля экрана на 360 / 390 / десктопе |
| Радиусы | 2–3 значения (например, поля, карточки, листы) |
| Тени и обводки | 2–3 уровня возвышения; тонкие обводки взамен теней там, где возможно |
| Иконки | один набор, размеры 16/20/24, толщина линии, цвета по состояниям |
| Контраст | таблица проверенных пар «текст/фон» (AA) |

### Компоненты (со всеми состояниями: default, hover/pressed, focus, disabled, error)

Кнопки (основная, вторичная, текстовая, опасная); поля ввода, в том числе **поле суммы** (ввод «1 234,50», суффикс ₽, ошибка); выбор конверта; чипы-фильтры; строки списков и карточки; таблицы с цифрами (выравнивание, итоги, залипающий первый столбец на узких экранах); бейджи статуса месяца (черновик, открыт, закрыт, открыт повторно — не только цветом); предупреждения и баннеры (info, warning, danger); модальные окна и нижние листы; переключатель месяца; таб-бар и боковая панель; пустые состояния; уведомления (toast); скелетоны загрузки; графики (сгруппированные столбцы, линии с выбором конвертов, легенда не только цветом).

Один канвас «**Family Budget — Design**». Страницы / группы кадров:

| 04 Прототип | кликабельный прототип основных сценариев |

Правила:

- **Гайдлайны канваса** = токены и правила из этого брифа (имя гайдлайна: «Токены», «Правила денег», «Анти-паттерны», «Доступность»); агент читает их перед каждой работой.
- **Закреплённые референсы** — образцы тона; новые кадры сверяются с ними.
- **Статусы кадров:** `draft` → `needs_review` → `ready_for_dev`. Статус `ready_for_dev` ставит **только владелец** (правка HTML или размера сбрасывает одобрение).
- **Ревью** — комментарии на кадрах и элементах; агент отвечает и закрывает треды после исправления; решения по вкусу записываются как «решения» холста.
- Демо-данные только из раздела 8; никаких lorem ipsum.
- Агент проверяет скриншот каждого кадра после создания и правит.
- Ссылку на канвас владелец вписывает в поле «Канвас:» этого файла.

## 8. Демо-данные для макетов

| --- | --- | --- | --- | --- |

| Подушка безопасности | 100 000,00 ₽ | 15 000,00 ₽ | перевод −5 000,00 ₽ в «Отпуск» | 110 000,00 ₽ |
| Развлечения | 3 000,00 ₽ | 8 000,00 ₽ | списание 14 500,00 ₽ («Концерт и ужин») | 0,00 ₽, непокрыто 3 500,00 ₽ |

Для состояний ошибок: распределение выше дохода (например, на 2 500,00 ₽), перевод 8 000,00 ₽ при доступных 5 000,00 ₽ (`MSG-03`), архивирование «Отпуска» с остатком 65 000,00 ₽ (`MSG-05`). Для аналитики — 12 месяцев 2026 года с правдоподобным разбросом (доход 150 000–165 000 ₽).

Суммы расчётные и иллюстративные: допустимо подправить, если сохраняется внутренняя согласованность (остаток = старт + распределение − списания ± переводы).
