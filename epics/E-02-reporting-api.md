# E-02. Отчётность API

## Ценность для пользователя

Сервер отдаёт готовые данные для главного экрана и аналитики: сводку месяца (доход, распределено, свободно, корректировки, непокрытое) и три годовых отчёта. Экраны (E-03, E-05) будут только отображать эти данные.

## Ключевые фичи

- Месячный дашборд с показателями по каждому конверту.
- Годовая аналитика: доход/распределение/свободные средства, балансы конвертов по месяцам, непокрытые операции.

## Охват правил спеки

- Дашборд: `UI-06`…`UI-09`, `FIN-11`, `FIN-12`, `HIST-12`, `API-12`.
- Аналитика: `REP-01`…`REP-11`, `API-13`.

## Критерии приёмки вехи

Владелец проверяет через Swagger на демо-данных:

1. `GET /api/v1/dashboard/monthly?period=…`: при доходе 100 000 ₽ и распределении 75 000 ₽ свободно 25 000 ₽ (`AC-02`).
2. Обычный перевод не меняет «Пополнено» и «Списано» (`AC-19`).
3. `GET /api/v1/analytics/yearly?year=…` возвращает три отчёта по 12 месяцам (`AC-20`); архивные конверты остаются в аналитике.
4. Интеграционные тесты зелёные и ссылаются на `AC-02`, `AC-19`, `AC-20`.

## Вне охвата

- Экраны (E-03, E-05).
- Экспорт отчётов.
