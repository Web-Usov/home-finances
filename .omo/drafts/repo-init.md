## Решения (с обоснованием)
1. **Нет скелета auth** — Спека MVP строка 417 говорит, что auth отсутствует. Clerk добавил бы ненужную сложность в приложение приватной сети.
2. **EAS только как заглушка** — Нативный mobile вне MVP (спека строка 594). Конфиг EAS обеспечивает будущие сборки, не блокируя текущую web-разработку.
3. **Заглушки для всех API-эндпоинтов** — Реализация всех 14 маршрутов как заглушек (с ответами 501 или mock) обеспечивает завершённость OpenAPI-спеки и немедленную генерацию клиентов Orval.
4. **Схема Prisma перед миграцией** — Сначала валидировать схему, затем генерировать миграцию. Предотвращает дрейф схемы.
5. **Общий пакет типов** — Централизация Zod-схем и TS-интерфейсов предотвращает дрейф типов между backend DTO и frontend формами.
